## 一、鼠标操作

| 操作 | 功能 | 说明 |
|------|------|------|
| **左键点击** (图标) | 打开应用 | 主页/桌面图标点击启动 |
| **左键点击** (← 返回胶囊) | 返回上级 | Settings/About 等页面顶部 |
| **左键点击** (底部 Home 指示条) | 打开 App Switcher | 屏幕正下方的毛玻璃横条 |
| **左键上滑** (底部 Home 指示条) | 打开 App Switcher | 按住后向上拖动 >30px 触发 |
| **左键点击** (卡片) | 切换至该应用 | App Switcher 中的应用卡片 |
| **左键点击** (✕ 关闭按钮) | 关闭应用 | App Switcher 卡片左上角红色按钮 |
| **左键点击** (空白区域) | 返回桌面 | App Switcher 背景点击关闭 |
| **左键长按** (输出区域) | 弹出复制菜单 | Terminal 中选中文字后 |
| **左键长按** (输入框) | 弹出粘贴菜单 | Terminal / Browser 输入区域 |
| **右键点击** | 粘贴 | Terminal 输入栏 |

## 三、窗口系统（MacWindow）

所有 App 在浮动圆角毛玻璃窗口中打开，多窗口可共存于纯黑背景。

| 操作 | 功能 |
|------|------|
| **拖拽标题栏** | 移动窗口位置 |
| 🔴 **红色按钮** | 关闭窗口 |
| 🟡 **黄色按钮** | 最小化窗口（App Switcher 中仍可选） |
| 🟢 **绿色按钮** | 全屏/恢复窗口 |
| **边缘拖拽**（左/右/下/角） | 缩放窗口大小 |
| **点击窗口** | 将该窗口置顶 |
| **空间位置按钮** | 直接选择正前、左侧、右侧或远处 |

### 📌 窗口钉选模式

标题栏右上角图钉按钮切换两种模式：

| 模式 | 图标 | 说明 |
|------|------|------|
| **悬停（Pinned）** | 白色图钉 | 窗口固定放置位置，屏幕滚动/转头时不动 |
| **视线跟随（Following）** | 青色发光图钉 | 窗口始终保持在视野中央附近 |

> 💡 硬件接上后，YUNSH 会自动接管头部追踪（通过系统服务 `yunsh-headtracking`）

## 五、系统功能

### 截图
- **方式一**: 按 **Print** 键
- **方式二**: 点击状态栏截图图标
- **方式三**: 点击右下角悬浮截图按钮
- **方式四**: 按 **Ctrl+Shift+S** 区域截图
- **方式五**: 控制中心 📷 按钮
- 截图后右上角显示叠加预览

### 控制中心
- **方式一**: 按 **Ctrl+Shift+C**
- **方式二**: 点击状态栏左侧 ☰ 图标

### App Switcher (多任务切换)
- **方式一**: 点击 Home 指示条（屏幕底部毛玻璃横条）
- **方式二**: 从 Home 指示条**按住向上拖拽**
- **方式三**: 按 **Ctrl+↑**

### 待机
- 2 分钟无操作自动进入待机（Screensaver）
- 移动鼠标即可唤醒

### 双目显示与校准

- 系统默认输出左右并排的同步双目画面。
- 进入“设置 → 空间显示”可切换双目/单画面开发模式。
- “双目校准画面”用于检查左右眼顺序、中心重合、裁切和比例。
- 瞳距用于记录佩戴配置；“水平融合”直接微调左右画面的相对位置。
- 桌面窗口位于共享舒适焦平面。真正的立体内容仍需后续应用级左右眼渲染通道。
- 当前空间桌面是 3DoF 视角相对布局，不是 6DoF 房间锚定。

### SpaceCapsule（空间胶囊）

- 从主屏幕打开“空间胶囊”。
- 输入空间名称并点击“保存并导出”。
- 系统把当前已打开应用、窗口尺寸、空间位置、固定/跟随状态和受支持的应用状态保存为 `.yunshspace` 文件。
- 文件位于 `/home/yunsh/Downloads`，可通过文件传输、U 盘或后续 YUNSH Flow 转发。
- 把收到的 `.yunshspace` 文件复制到另一台 YUNSH OS 的 Downloads，刷新列表并点击“恢复”。
- 导入前系统会校验文件格式、版本、大小和应用白名单。
- 当前浏览器可恢复网页地址；终端命令、密码和任意第三方应用私有状态不会写入胶囊。

### Comfort DNA（舒适指纹）

- 激活时可选择“稳定”“平衡”或“灵敏”，也可以点击“以后再设置”直接跳过。
- Comfort DNA 只调整本机头追平滑、视野和减少动效选项，不上传原始运动数据。
- 激活后可在“设置 → Comfort DNA”重新选择。
- “稳定”更重视平滑与减少大幅运动；“平衡”是推荐默认值；“灵敏”优先响应速度与视野。

### 激活向导（首次开机）
- 欢迎 → 选择语言 → 连接 Wi-Fi → 设置账户（可跳过）→ Comfort DNA（可跳过）→ 初始化
- 跳过则使用默认账户 `yunsh:yunsh123`
