## 一、鼠标操作

| 操作 | 功能 | 说明 |
|------|------|------|
| **左键点击** (图标) | 打开应用 | 主页/桌面图标点击启动 |
| **左键点击** (← 返回胶囊) | 返回上级 | Settings/About 等页面顶部 |
| **左键点击** (底部 Home 指示条) | 打开 App Switcher | 屏幕正下方的毛玻璃横条 |
| **左键上滑** (底部 Home 指示条) | 打开 App Switcher | 按住后向上拖动 >30px 触发 |
| **左键点击** (卡片) | 切换至该应用 | App Switcher 中的应用卡片 |
| **左键点击** (✕ 关闭按钮) | 关闭应用 | App Switcher 卡片左上角红色按钮 |
| **左键点击** (空白区域) | 返回桌面 | App Switcher 背景点击关闭 |
| **左键长按** (输出区域) | 弹出复制菜单 | Terminal 中选中文字后 |
| **左键长按** (输入框) | 弹出粘贴菜单 | Terminal / Browser 输入区域 |
| **右键点击** | 粘贴 | Terminal 输入栏 |

## 三、窗口系统（MacWindow）

所有 App 在浮动圆角毛玻璃窗口中打开，多窗口可共存于纯黑背景。

| 操作 | 功能 |
|------|------|
| **拖拽标题栏** | 移动窗口位置 |
| 🔴 **红色按钮** | 关闭窗口 |
| 🟡 **黄色按钮** | 最小化窗口（App Switcher 中仍可选） |
| 🟢 **绿色按钮** | 全屏/恢复窗口 |
| **边缘拖拽**（左/右/下/角） | 缩放窗口大小 |
| **点击窗口** | 将该窗口置顶 |
| **空间位置按钮** | 直接选择正前、左侧、右侧或远处 |

### 📌 窗口钉选模式

标题栏右上角图钉按钮切换两种模式：

| 模式 | 图标 | 说明 |
|------|------|------|
| **悬停（Pinned）** | 白色图钉 | 窗口固定放置位置，屏幕滚动/转头时不动 |
| **视线跟随（Following）** | 青色发光图钉 | 窗口始终保持在视野中央附近 |

> 💡 硬件接上后，YUNSH 会自动接管头部追踪（通过系统服务 `yunsh-headtracking`）

## 五、系统功能

### 截图
- **方式一**: 按 **Print** 键
- **方式二**: 点击状态栏截图图标
- **方式三**: 点击右下角悬浮截图按钮
- **方式四**: 按 **Ctrl+Shift+S** 区域截图
- **方式五**: 控制中心 📷 按钮
- 截图后右上角显示叠加预览

### 全局菜单栏

- 左上角 YUNSH：打开系统菜单。菜单包含 Wi-Fi、蓝牙、键盘、全屏/区域截图、录屏、专注、显示、相册、设置、更新、锁定、重启、关机和恢复出厂。
- 中间 YUNSH / METAVERSE：进入系统级 `YUNSH META Universe` 世界层；它不是普通 App。
- 右上角 Orbit：打开系统 Agent 的对话和设置。

### Orbit

- Orbit 每次开机自动启动，但故障不会阻止桌面显示。
- 首次激活可选择 DeepSeek 或 Kimi、模型版本、自己的 API Key 和声音，也可以跳过。
- 激活后可在 Orbit 设置中使用 DeepSeek、Kimi 或 OpenAI 兼容提供商。
- API Key 使用设备密钥加密保存在本机，界面不会重新显示完整内容。
- Orbit 使用“计划 → 执行 → 观察 → 验证”循环处理多步任务，并可读取界面状态、截图/OCR、录屏、管理窗口、处理文件、运行命令和保存经授权的任务记忆。
- 功能类别可分别关闭；首次使用敏感工具时可选择“仅本次允许”“始终允许”或“拒绝”。破坏性命令、电源和恢复操作不能永久授权。
- 默认声音为甜美女声，也可切换男声；语音识别需要外接 USB 或蓝牙麦克风。

### YUNSH 系统菜单
- **方式一**：点击左上角 YUNSH 液态玻璃悬浮按钮
- **方式二**：外接键盘按 **Ctrl+Shift+C**
- 回正不放在菜单内，始终使用独立蓝色“回正”按钮。

### App Switcher (多任务切换)
- **方式一**: 点击 Home 指示条（屏幕底部毛玻璃横条）
- **方式二**: 从 Home 指示条**按住向上拖拽**
- **方式三**: 按 **Ctrl+↑**

### 待机
- 2 分钟无操作自动进入待机（Screensaver）
- 移动鼠标即可唤醒

### 双目显示与校准

当前眼镜驱动接收一个完整画面，并把同一画面同步显示到左右两块屏幕。
因此系统默认使用完整单画面输出，插入普通显示器也能直接显示。高级
Side-by-Side 只为未来能独立接收左右眼画面的驱动板保留，当前硬件不要开启。

- 系统默认输出左右并排的同步双目画面。
- 进入“设置 → 空间显示”可切换双目/单画面开发模式。
- “双目校准画面”用于检查左右眼顺序、中心重合、裁切和比例。
- 瞳距用于记录佩戴配置；“水平融合”直接微调左右画面的相对位置。
- 桌面窗口位于共享舒适焦平面。真正的立体内容仍需后续应用级左右眼渲染通道。
- 当前空间桌面是 3DoF 视角相对布局，不是 6DoF 房间锚定。

### SpaceCapsule（空间胶囊）

- 从主屏幕打开“空间胶囊”。
- 输入空间名称并点击“保存当前空间”。
- 系统把当前已打开应用、窗口尺寸、空间位置、固定/跟随状态和受支持的应用状态保存为 `.yunshspace` 文件。
- 选择“发送”，系统会通过 Bonjour 发现同一 Wi-Fi 或 iPhone 热点中的 YUNSH OS，并使用 TLS 加密发送。
- 接收设备会显示发送方、空间名称和窗口数；只有点击“接受并恢复”后才会导入。
- 文件也保存在 `/home/yunsh/Downloads`，可以作为离线备份。
- YUNSH Link 的 Drop 页面可以用已配对密钥加密导入胶囊，再通过 iOS 分享面板转发到微信、文件、隔空投送或其他 App。
- 导入前系统会校验文件格式、版本、大小和应用白名单。
- 当前浏览器可恢复网页地址；终端命令、密码和任意第三方应用私有状态不会写入胶囊。

### Comfort DNA（舒适指纹）

- 激活时可选择“稳定”“平衡”或“灵敏”，也可以点击“以后再设置”直接跳过。
- Comfort DNA 只调整本机头追平滑、视野和减少动效选项，不上传原始运动数据。
- 激活后可在“设置 → Comfort DNA”重新选择。
- “稳定”更重视平滑与减少大幅运动；“平衡”是推荐默认值；“灵敏”优先响应速度与视野。

### 激活向导（首次开机）
- 多语言“你好 / Hello”欢迎 → 选择语言 → Wi-Fi → 配对眼镜（可跳过）→ 配对 iPhone（可跳过）→ 账户（可跳过）→ Comfort DNA（可跳过）→ 初始化
- 眼镜配对页显示搜索、选择、安全配对和完成进度。
- iPhone 配对页先提示下载并打开 YUNSH Link，再显示一次性 6 位密钥；密钥不区分大小写、不使用二维码、10 分钟有效且使用后失效。
- 激活后可在“设置 → YUNSH 眼镜”或“设置 → YUNSH Link / iPhone”重新配对。
- 跳过则使用默认账户 `yunsh:yunsh123`
- “设置 → 开机密码”会先验证当前密码；修改成功后，本地 YUNSH 凭据与 Linux 用户 `yunsh` 的密码会同步更新。

### iPhone Screen Relay（投屏窗口）

- 在 YUNSH Link 完成密钥配对，并让 iPhone 与 YUNSH OS 处于同一 Wi-Fi 或 iPhone 热点。
- 打开 YUNSH Link 的 Display 页面，点击系统广播按钮并在 iOS ReplayKit 面板中明确开始。
- YUNSH OS 打开“iPhone 投屏”后，画面作为普通空间窗口显示，可移动、缩放、固定、跟随或放到四种空间预设。
- iOS 不允许静默录屏；每次广播都由用户主动开始。当前功能不会把每个 iOS App 拆成独立空间窗口。

### Orbit 双端对话

- 眼镜中的右上角 Orbit 悬浮入口会打开完整对话界面，可配置 API 提供商、模型、API Key 和声音。
- 独立 Orbit iPhone App 复用 YUNSH Link 已完成的设备配对，连接同一个系统 Agent，可继续对话、配置提供商/模型/API Key，并处理“仅本次允许 / 始终允许 / 拒绝”。
- 手机端不保存 API Key；密钥通过已配对、TLS 加密的本地 Wi-Fi 或 iPhone 热点链路提交，由 YUNSH OS 使用设备密钥加密保存。
- Orbit 的实际工具仍在 YUNSH OS 上执行。重启、关机、恢复出厂和破坏性 Shell 操作不会因从 iPhone 发起而绕过二次确认。

### YUNSH Flow（照片、文件与剪贴板）

- 在 YUNSH Link 的 Flow 页面主动选择照片后，内容经已配对的 TLS 本地链路保存到 YUNSH OS 的 `Downloads/YUNSH Flow`。
- 可从 YUNSH OS 取回 Flow 文件，再调用 iOS 分享面板发送到隔空投送、微信、文件或其他 App；系统不复制 Apple 私有 AirDrop 协议。
- “发送剪贴板”和“接收剪贴板”都必须由用户点击，不在后台静默读取 iPhone 剪贴板。
- 室内可使用同一 Wi-Fi；外出时让 Pi/随身计算模块连接 iPhone 个人热点。首次需用户开启热点，保存后由 Linux 网络服务自动重连。
