# YUNSH OS v3.1.4

v3.1.4 is a boot-and-desktop reliability release. It adds an early SSH
recovery channel for first-boot and display failures. The boot partition
carries the Raspberry Pi OS `ssh` marker and the clean root filesystem enables
`ssh.service`, so a device remains inspectable while online package
installation or the Pi 5 DRM/Weston hand-off is still being diagnosed.
Firstboot also starts SSH before waiting for the network. The post-reboot
health guard no longer waits for `network-online.target`.

The desktop reliability fixes are part of the same image: WebEngine is lazy
loaded only when the browser is opened, Fcitx starts only after the Wayland
compositor is ready, invalid full-screen photo anchors are removed, and
visible version fallbacks consistently report v3.1.4. These changes keep
optional browser/input services from crashing or delaying the first desktop.

The OTA archive updates the root filesystem. The boot-partition SSH marker is
included in the full image, so installing the full image is required when a
device still has an older boot partition.

This release does not treat linuxfb as the normal display path; Pi 5 KMS/DRM
and Weston remain the primary desktop path, with framebuffer recovery only
when the runtime explicitly detects a failure.
