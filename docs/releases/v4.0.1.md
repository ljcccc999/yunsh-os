# YUNSH OS v4.0.1

v4.0.1 is a small legacy OTA bridge between the v4.0 updater and the v4.1
delta OTA system.

- v4.0 devices install this release using the existing `yunsh-ota-v1`
  archive format.
- The bridge updates the OTA updater, update daemon, services, and user-space
  files; it does not rewrite the boot partition or kernel firmware.
- After rebooting into v4.0.1, the device can download the v4.1 manifest and
  only the changed content chunks.
- A full image remains necessary when the installed Pi 5 boot firmware,
  kernel/initramfs/DTB/overlay, or `/lib/modules` ABI is not already the
  validated baseline.
