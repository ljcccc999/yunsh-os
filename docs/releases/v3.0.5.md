# YUNSH OS v3.0.5

YUNSH OS v3.0.5 hardens the local lock boundary, input-method switching,
keyboard focus behavior, and the iOS-style background App Switcher.

## Highlights

- Orbit, the system menu, and the App Switcher are unavailable while the
  device is actively locked. Orbit cannot be used to bypass the local unlock
  password.
- Password-required lock screens focus the local password field and show the
  shared keyboard; automatic smart wake does not open a keyboard.
- The keyboard follows the focused editor and closes after focus is lost. The
  globe key and YUNSH input-method tile use the daemon's authoritative toggle
  state, so switching remains consistent after restart or external keyboard
  use.
- Minimized applications are immediately retained as tappable background cards
  and closed cards are removed from the running-app model.
- The Android preparation error/retry behavior from v3.0.4 remains included.

## Validation boundary

The source is checked with QML, Python and shell validation, then rebuilt with
the protected Raspberry Pi 5 firmware layer, rootfs/ext4 checks, OTA manifest
checks, and the non-writing macOS flasher check. Real lock-screen input,
Fcitx5 switching, Waydroid graphics, and external-display behavior still need
Raspberry Pi 5 hardware validation.
