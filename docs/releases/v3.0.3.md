# YUNSH OS v3.0.3

YUNSH OS v3.0.3 improves first-install reliability and makes Wi-Fi and spatial
text input easier to diagnose and use.

## Highlights

- Firstboot now separates package download from unpacking and configuration.
  When APT exposes package sizes, the local installation surface reports real
  downloaded MB against total MB instead of appearing frozen at a coarse
  stage percentage.
- APT downloads use finite connection timeouts and retries. Firstboot checks
  Internet reachability before each package group and attempts to restore the
  active network stack automatically when connectivity is lost.
- NetworkManager is activated and verified immediately after its package group
  is installed, before later online font and graphics packages need the link.
  A failed handoff exits cleanly so systemd can retry firstboot; a forced power
  cycle is not part of the supported installation flow.
- Activation automatically searches nearby Wi-Fi networks every 15 seconds,
  supports manual refresh and manual SSID fallback, and lets the user select a
  discovered network before entering its password.
- Wi-Fi connection handling refreshes scan data, targets the detected wireless
  interface, retries after removing an exact stale SSID profile, and verifies
  association plus DHCP before reporting success. The activation UI no longer
  declares failure after only ten seconds.
- The system virtual keyboard reconciles delayed QML focus changes so native
  fields reliably reopen it. The layout now includes brackets, braces,
  hyphen/underscore, slash/question mark, backslash/pipe and cursor movement
  controls in addition to its existing number, letter, punctuation, Shift,
  Backspace, Space and Enter keys.
- Desktop application icons remain visible indefinitely when no application
  window is open. With a window visible, an exposed-desktop click shows the
  icons temporarily and starts or refreshes a 30-second hide timer. The
  top-left YUNSH menu remains the only persistent manual hide/show control.
- Wi-Fi regulatory-country setup, radio unblocking, live Ethernet detection,
  and direct status queries prevent correct credentials being rejected by a
  disabled radio or stale UI state. Bluetooth is also unblocked, powered,
  pairable, and scanned automatically when its settings page opens.
- The root filesystem grow service now normalizes and validates the partition
  number before calling `growpart`; a failed partition expansion is reported
  as a failure instead of being mistaken for success.
- Network time and the Asia/Shanghai timezone are synchronized in a separate
  non-blocking boot service. A new graphical lock-password switch affects only
  the lock screen and never changes the Linux terminal/SSH password.
- The keyboard adds a dedicated symbol layout, repeat-on-hold Backspace,
  readable orientation controls, momentary ordinary-key highlighting, and a
  WebEngine input bridge for browser fields and Enter/form submission.
- Browser windows clip their complete material to the rounded frame and add
  multiple closable tabs. Only the initial tab opens Bing; later tabs start
  blank. New-window requests open in a new tab.
- Photos now use a liquid-glass Photos/Albums selector, confirmation before
  deletion, Recently Deleted with a second permanent-delete confirmation,
  restore, Hide, and Unhide flows.
- Orbit and common window/card surfaces use brighter, less transparent liquid
  glass, complete corner clipping, and bounded text columns to avoid clipped
  built-in labels. META Universe keeps its English product name while its
  descriptions follow Simplified or Traditional Chinese system language.
- Android readiness now requires the actual system and vendor images plus a
  usable Wayland display; a leftover configuration file can no longer make an
  incomplete runtime appear ready.
- The lock screen explicitly requests the shared keyboard when its password
  field receives focus. Orbit chat, voice, approvals, configuration and
  permission changes are rejected by the local runtime until the device is
  unlocked with the local password. Password verification uses PAM on Debian
  releases where Python no longer provides the old `crypt` module.
- Orbit voice chat has an explicit exit control and hides its microphone entry
  when no provider, microphone, or local recognition model is ready. The image
  includes Fcitx5 Chinese input, CJK/emoji fonts, and PulseAudio Bluetooth
  audio support for paired speakers.
- Long-press editing keeps the Copy/Paste/Select All menu for native fields;
  Paste first consumes text explicitly delivered through the paired YUNSH Flow
  clipboard channel and otherwise falls back to the local native clipboard.
  The root-grow path expands the second partition and filesystem to the
  available SD-card capacity on first boot.

## Validation boundary

The release is checked incrementally through QML, Python and shell validation,
image construction, boot/rootfs embedded-file and systemd dependency checks,
XZ/SHA-256 verification, OTA manifest inspection and the macOS flasher's
non-writing check mode. The exact v3.0.3 archive still requires a fresh
Raspberry Pi 5 burn to validate the exact rebuilt archive. The earlier v3.0.3
source was deployed to a running Pi 5 and verified for service startup,
framebuffer UI, nearby Wi-Fi scanning, simultaneous Ethernet/Wi-Fi association
and DHCP, wireless Internet reachability, NTP synchronization, Bluetooth
controller availability, and online root-filesystem expansion. The Pi was then
unplugged before this final archive rebuild, so the last keyboard, Photos,
browser, window and clipboard edits require post-burn hardware testing, along
with fresh-image firstboot, Android image download/Wayland rendering and all
touch/drag gestures.
