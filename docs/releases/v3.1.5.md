# YUNSH OS v3.1.5

v3.1.5 fixes the background app switcher and the final desktop hand-off paths
that were still unreliable on a large display. Minimized native and Android
windows remain registered as background cards, the switcher is rendered above
floating app surfaces, and a full-width bottom gesture target makes the
upward swipe reliable instead of requiring a precise hit on the small pill.

Minimizing a window now releases the shared virtual keyboard so it cannot cover
the home gesture or remain visible after the app is gone. The release also
includes the current lock/input, pairing, liquid-glass modal, browser, and
Orbit persistence fixes from the 3.1.x line.

The image and OTA bundle pass QML, shell, Python, XZ, SHA-256, partition,
rootfs, embedded-file, first-boot-state, systemd-link, and OTA manifest
checks. The updated UI has been deployed to the connected Raspberry Pi for
live service verification; the complete image still requires a fresh Pi 5 SD
burn for hardware/display validation.
