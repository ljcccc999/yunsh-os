# YUNSH OS v3.1.2

This release consolidates the boot, OTA, input, browser, window, and Screen
Relay fixes requested after v3.1.1.

- OTA manual checks are informational; explicit downloads are single-flight,
  recorded in history, and automatic installation is limited to idle/night
  windows before one verified reboot.
- Normal Pi 5 boots no longer expose the Raspberry Pi firmware splash or tty1
  systemd/getty text. Serial and journal diagnostics remain available.
- Fcitx5 starts after the Wayland session with its session bus shared with QML;
  the virtual keyboard shows Pinyin composition and long-press/right-click
  liquid-glass copy/paste actions.
- App Switcher, recoverable edge dragging, Screen Relay corner clipping,
  browser WebGL, horizontal URL scrolling, and recent-download management are
  included.

The image targets Raspberry Pi 5. A real cold boot, display, BLE, Android,
and iPhone Relay test still requires the target hardware.
