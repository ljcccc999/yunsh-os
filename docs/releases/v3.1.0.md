# YUNSH OS v3.1.0

YUNSH OS v3.1.0 is a Raspberry Pi 5 stability update focused on the display
startup path, input method switching, clipboard behavior, and browser input.

## Highlights

- The launcher starts Fcitx5 inside a persistent D-Bus session, allowing the
  globe key and the YUNSH input-method control to switch between US keyboard
  and Pinyin after reboot and after the framebuffer fallback is selected.
- Copy and paste now use the explicit Flow clipboard first, then the last
  local copy, and finally an empty value. Editable fields, browser URL copy,
  and terminal copy all write through the same local clipboard bridge.
- New browser tabs open to an empty editable address surface without exposing
  `about:blank`; browser back, forward, refresh, and navigation actions release
  the web-page input focus before changing pages.
- The Pi DRM dead-socket recovery remains enabled, with a device policy marker
  that keeps the current Pi 5 display profile on the tested Qt linuxfb path
  until DRM plane negotiation is revalidated.
- The installation/update card remains free of the overlapping placeholder
  `Title` label.

## Validation boundary

The source is checked with Python, shell, and QML tooling, and the full image
and OTA bundle are checked for XZ integrity, SHA-256, partition layout, ext4
integrity, embedded files, systemd desktop dependencies, and OTA allow-list
compatibility. The clipboard and input-method API paths were also exercised
over SSH on the currently connected Raspberry Pi. A fresh SD-card burn and
external Bluetooth mouse/display regression still require physical hardware
testing after the image is installed.
