# YUNSH OS v3.0.1

YUNSH OS v3.0.1 refines spatial text input and the system-level Orbit surface
without changing the Raspberry Pi 5 platform foundation.

## Highlights

- The virtual keyboard can switch between an upright reading plane and a
  desk-like pitched plane, and between pinned and gaze-following behavior.
- The keyboard remains movable and now opens for native YUNSH OS application
  text fields. Its input plane and z-order no longer collide with Orbit's
  composer.
- Orbit is directly movable within safe screen bounds and shifts away from the
  keyboard while text entry is active.
- Orbit adds the same Low, Medium, and High reasoning profile control used by
  the iPhone app; the selected profile is passed to the local runtime.
- Orbit settings now have an explicit Back action and a clear API-key
  replacement path while continuing to keep the saved key encrypted and hidden.
- The image builder selects and validates a device-specific Raspberry Pi 5
  boot firmware layer before modifying the image.

## Validation

This release was checked through QML, Python, and shell static validation,
image construction and structural inspection, boot/rootfs embedded-file and
systemd-link checks, XZ/SHA-256 verification, OTA manifest inspection, and the
macOS flasher's non-writing `--check` mode.

Per the requested test scope, no virtual-machine boot was run. This exact image
was also not reflashed to a Raspberry Pi 5, so earlier v3.0.0 framebuffer and
BLE evidence is not presented as validation of this v3.0.1 archive. Real Pi 5
startup, display, motion hardware, microphone, Android GPU/binder behavior, and
optical-display interaction remain hardware-validation boundaries.
