# YUNSH OS v2.0.1

YUNSH OS v2.0.1 makes the persistent world and Orbit first-class parts of the
operating system while retaining all v2.0.0 workspace, device-continuity,
comfort, Android, and spatial-window capabilities.

## System world

- YUNSH META Universe is now a shell-owned persistent world layer rather than
  a normal application.
- A permanent global bar provides the YUNSH system menu, central
  YUNSH/METAVERSE world entry, and Orbit entry.
- The world foundation opens with `Get Ready for YUNSH META Universe`.

## Orbit

- Orbit is a system-level agent runtime that starts automatically at boot
  without becoming a desktop-start dependency.
- Choose an API provider, then a model, then enter a personal API key.
- DeepSeek, Kimi, and custom OpenAI-compatible endpoints are supported.
- Provider credentials are encrypted with a device-local key, the API is
  loopback-only, and full credentials are never returned to the UI.
- Application, file, shell, settings, network, screen, memory, and world tools
  are enabled by default and can be disabled individually.
- The activation flow can configure or skip Orbit; configuration remains
  available from the global Orbit panel.
- A sweet female voice is selected by default, with a male alternative.
  Optional natural speech and local Chinese recognition prepare in the
  background. Recognition requires a detected USB or Bluetooth microphone.
- The selected black-and-white open-O liquid-glass identity is used throughout
  the shell.

## Display and interface

- The default output is one complete frame. The current glasses controller
  mirrors that frame to both eye displays, and a conventional monitor shows
  the same complete desktop.
- Advanced side-by-side output remains available only as a future-controller
  compatibility option.
- Built-in applications use a more consistent white liquid-glass icon system
  designed for optical-black transparent AR displays.

## Retained capabilities

- SpaceCapsule export, validation, restoration, encrypted YUNSH Drop, receiver
  approval, and YUNSH Link share-sheet forwarding.
- User-authorized encrypted iPhone Screen Relay as a spatial window.
- Multilingual Hello activation, skippable glasses and phone pairing with
  progress, case-insensitive single-use phone keys, and optional Comfort DNA.
- Browser, terminal, screenshots and photos, settings, Wi-Fi, Bluetooth, OTA,
  factory reset, virtual keyboard, 3DoF layouts, recenter, Waydroid, F-Droid
  fallback, and APK side-loading.

## Validation boundary

The final image passed XZ and SHA-256 integrity, ext4, boot-partition,
embedded-source, required-file, systemd-enable, desktop-dependency, OTA
manifest, Python, shell, static QML, Orbit encryption/tool/UI-bridge,
SpaceCapsule, Comfort DNA, display-preference, pairing, Screen Relay, firmware
protocol, and non-writing flasher checks.

Physical Raspberry Pi 5 boot, optical output, glasses controller behavior,
Bluetooth motion hardware, microphone input, iPhone ReplayKit streaming,
Waydroid applications, and full performance still require validation on the
intended hardware.
